Release history

Every release, newest first. Each one ships as a portable zip on GitHub — and the app updates itself.

v1.3.2latest
oct 2026
VNC consoles stay open
  • An open VNC console no longer times out when left idle: Dshh now sends a little traffic at least every 20 seconds, so console proxies don't drop it as idle, and the short-lived console token isn't needed again while the tab stays connected
  • If a console drops anyway — a network blip, a proxy restart — Dshh reconnects on its own with the same token while the proxy still accepts it, and only asks for a fresh link once it doesn't
  • Fixed: the local terminal menu could be cut off at the window's edge when the sidebar was narrow
v1.3.1
oct 2026
Copy files straight between two servers
  • The split view's second pane can now show another saved server instead of your disk — pick it from the new source menu. Drag files and folders between the two panes, or select them and press Copy
  • The copy runs on the server itself: Dshh starts OpenSSH's sftp there (or curl when the other server is FTP), so the data goes from server to server and never through your PC. Progress shows as usual, and Stop really ends it on the server
  • The other server's password is typed into the prompt, never put on a command line or written to disk; a key-based login is lent for the length of the copy through agent forwarding, so the key file stays on your PC
  • When a server reaches the other one at a different address than your PC does — a private IP, an internal name — set it once from the pane's footer and it is remembered
  • Fixed: in development builds, SSH terminal tabs could stay stuck on “connecting”
v1.3.0
oct 2026
VNC remote desktop, bulk file actions and Ctrl+scroll zoom
  • A new VNC tab shows the remote screen with keyboard, mouse and clipboard, scaled to fit or at 1:1, plus view-only and a Ctrl+Alt+Del button. Like every other protocol it runs inside dshh.exe — no viewer to install
  • Logs in with a VNC password, VeNCrypt over X509 TLS (with a username and password where the server wants one) or Apple Remote Desktop for macOS Screen Sharing. A rejected password asks again instead of leaving a dead tab
  • Paste an OpenStack or Huawei FusionSphere console link (vnc_auto.html?token=…) and the VM's console opens straight in Dshh. Save the console proxy as a connection and only the short-lived token is asked for each time; its host can be picked from a saved SSH session
  • Route any VNC connection through a saved SSH session, so the unencrypted VNC stream never crosses the network bare
  • Type clipboard keys text into consoles that have no clipboard — BIOS screens, KVM consoles, login prompts. On QEMU/KVM it sends physical key codes, so the guest's own keyboard layout applies
  • Select files and folders in the SFTP and FTP browser — checkboxes, click, Ctrl+click, Shift+click or Ctrl+A — then download, delete, change permissions or change owner in one go. Folders come with everything inside, and a folder download recreates the tree on your disk
  • Delete asks first and counts what the selected folders hold before the button arms. Symlinks are never followed, so a link can't drag something outside the selection along
  • Permissions as an rwx grid or octal, optionally into folders — with folders kept openable when you apply something like 644. SFTP also changes owner and group by name; FTP uses SITE CHMOD. A new perms column shows each entry's rights
  • Ctrl+scroll zooms the terminal font, the file list and the VNC screen. Each connection remembers its own zoom; Ctrl+0 resets
v1.2.0
sep 2026
Sort, group and search the file browser
  • Sort SFTP and FTP listings by name, type, size or date — click a column header, or pick from the new sort menu. Names sort naturally, so file2 comes before file10
  • Group a folder by type (code, images, archives…), by date (today, yesterday, last 7 days…) or by Explorer-style size bands. Groups fold away with a click
  • A filter box narrows the folder as you type, with * wildcards. Press Enter and it searches every subfolder on the server instead, streaming matches in with a stop button; each result shows where it lives and jumps to its folder
  • The local pane in split view gets the same sort, group and filter, and each pane remembers its own choice between sessions
v1.1.3
sep 2026
Corrected credentials are kept by default
  • A password typed into the auth-failure prompt is now saved to the session by default, with no checkbox to tick each time — being asked at all means what was stored is wrong or missing. Settings › General turns the write off if you would rather each retry be one-time
  • A session saved without a username asks for one alongside the password, and keeps both
  • The connect banner drops its Dshh masthead and starts at the session line, so the box is three lines shorter
v1.1.2
sep 2026
Retry a wrong password, colour on connect
  • A saved session whose password the server rejects now asks for it again instead of leaving a dead tab. Type the right one and it connects, and the corrected password is written back to the saved session — but only after the server accepts it, so a second wrong guess never overwrites a working one. Covers SSH, SFTP and FTP, and asks for the key passphrase where that is what failed
  • A MobaXterm-style connect banner: a coloured box at the top of each session with the target, port, auth method, jump host, saved forwards and login command. It scrolls away with the session and lands in the log
  • The terminal status bar is drawn as coloured segments — green connected, amber connecting, red on error — with a clock alongside the uptime, grid and encoding
  • The accent colour set on a connection now tints that session's toolbar and status bar, so prod doesn't look like staging
  • All three are on by default and switch off individually in Settings › General
v1.1.1
aug 2026
Reorder quick commands and macros
  • Quick commands can be reordered — drag a row by its grip in the manage dialog and the chips above the compose bar follow that order, so the ones you actually use sit where your eye lands
  • Macros get the same handle, reordered the same way
  • Both lists also move with the keyboard: focus a grip and press the up or down arrow, which beats dragging inside a scrolling dialog
v1.1.0
aug 2026
Paste guard, transfer progress, file owners
  • Pasting two or more lines now asks first, listing the exact numbered lines that would run — every newline is an Enter to the shell, so a stray copy used to execute commands with no warning. Covers Ctrl+V, Ctrl+Shift+V, Shift+Insert and right-click paste; switch it off in Settings › Terminal
  • Uploads and downloads show a real progress bar with bytes moved, percentage and position in a multi-file batch, in the SFTP/FTP browser and the SCP dialog. Servers that won't report a size get an indeterminate bar rather than a fake percentage
  • The file browser has an owner column. SFTP resolves numeric uids against the server's own /etc/passwd, so you see root and www-data rather than 0 and 33; FTP reads the names straight out of its listing
v1.0.1
aug 2026
Right-click copy and paste
  • Right-clicking the terminal now pastes the clipboard. Select text first and the same right-click copies it instead — so select, right-click, right-click again copies a line and pastes it back without touching the keyboard
  • Fixed: a quick command typed into the new-row fields is saved when you press Done, instead of being discarded unless you started a second one
v1.0.0
jul 2026
1.0 — forwarding in every direction, macros, agent auth
  • Port forwarding now covers all three OpenSSH directions: local (-L), remote (-R, where the server listens on your behalf) and dynamic (-D), which runs a built-in SOCKS5 proxy
  • Every running forward shows live byte counters and an indicator that flashes on real traffic, so you can tell an idle tunnel from a busy one
  • SSH agent authentication — the private key never enters Dshh. Uses the Windows OpenSSH agent service, falling back to Pageant
  • Macros: record the commands you type in a terminal, name them, and replay the sequence into any session from the bottom dock
  • Optional terminal status bar with the target, time connected, grid size and encoding, plus indicators for logging, macro recording and running forwards
  • Optional Windows 11 Mica or acrylic backdrop behind the app chrome. The terminal itself stays opaque
  • Tabs carry a per-protocol icon, so a long row of sessions is scannable without reading labels
  • Settings is now organised into four tabs — General, Terminal, Output & logs, Security — instead of one long scroll
  • Font and line height are dropdowns rather than free text. The font list shows only the monospace faces actually installed on your machine, each rendered in its own face
  • Session logs default to a logs folder inside the portable data folder, so they travel with the app and auto-logging works without picking a folder first
  • The portable download is now a folder — dshh.exe beside its own data/ — so settings and saved connections travel with it to another machine or a USB stick
  • Upgrading from a non-portable build carries your existing settings and saved connections across on first run, leaving the originals untouched
